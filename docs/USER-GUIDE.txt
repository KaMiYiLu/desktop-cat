桌面猫咪 · v{{VERSION}} Windows 便携预览版

解压整个文件夹到可写目录，双击 DesktopCat.exe，无需安装。
启动后只显示猫咪。右键系统托盘里的猫咪图标，选择打开控制台，可演示动作或切换开关。
左键按住猫咪可拎起，放下后会有随机反应。
默认允许攻击鼠标，可在控制台关闭；跟随鼠标与拖动窗口默认关闭。
声音总开关控制全部声音，脚步声还有单独开关。

按住 Esc 约 3 秒或选择托盘菜单里的退出猫咪，可以退出程序。
关闭控制台只关闭面板，猫咪仍继续活动。
设置自动保存在 config.ini。程序不创建运行日志。
反馈问题时请描述版本、触发动作和错误提示。
卸载时先退出猫咪，再删除解压后的文件夹即可。

需要 Windows 与系统 .NET Framework 4.x。当前为开发预览版，尚未完成多屏、高 DPI 与各 Windows 版本的完整验证，尚未做发布者数字签名。请勿同时启动多个副本。
