桌面猫咪 · v{{VERSION}} Windows 便携预览版

解压整个文件夹到可写目录，双击 DesktopCat.exe，无需安装。
启动后只显示猫咪，不显示系统托盘图标。按住 Esc 并右键点击猫咪打开控制台，可演示动作或切换开关。关闭允许抓猫后仍可使用。
左键按住猫咪可拎起，放下后会有随机反应。
默认允许攻击鼠标，可在控制台关闭；跟随鼠标与拖动窗口默认关闭。
声音总开关控制猫叫、呼噜、脚步和咬鼠标音效，脚步声还有单独开关。咬住鼠标时播放一次轻声咬击，音量低于猫叫。

单独按住 Esc 约 3 秒退出程序。使用 Esc + 鼠标右键打开控制台后，本次 Esc 长按不会退出；如需退出，先松开 Esc，再重新长按。
关闭控制台只关闭面板，猫咪仍继续活动。
首次正常运行默认开启登录 Windows 后自启动，不需要管理员权限。控制台底部可取消；手动关闭后不会被下次启动重新打开。
自启动开启时，换新版或移动程序后正常运行一次即可刷新注册路径。请保留程序文件夹。
动作与声音设置自动保存在 config.ini；自启动及其偏好保存在当前用户注册表。程序不创建运行日志。
反馈问题时请描述版本、触发动作和错误提示。
卸载时先在控制台取消开机自启动，再退出猫咪并删除解压后的文件夹。

需要 Windows 与系统 .NET Framework 4.x。当前为开发预览版，尚未完成多屏、高 DPI 与各 Windows 版本的完整验证，尚未做发布者数字签名。请勿同时启动多个副本。
